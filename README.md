# AI-Racing-Test

Small browser racing experiment implemented in a single `index.html` file with Three.js. The scene includes a procedurally drawn sky, a moving track and keyboard/touch controls.

## Run

```sh
python3 -m http.server 8080
```

Open `http://localhost:8080`. Three.js is imported from unpkg, so a network connection and a browser with WebGL and JavaScript modules are required.

## Scope

This is an experimental game scene. The repository name is not evidence of AI-generated code or a trained racing agent; the current default branch does not document a model, training pipeline or evaluation.
